# wsp-002 · Workspace honours `--profile` tiers

- **Status:** ✅ done · closed 2026-07-27 · **Depends on:** `wsp-001`

## What was wrong

`create.mjs` has computed `tier` from `--profile` and passed it into `generateWorkspace` since
`ws-003` — but `generateWorkspace` never read the option. Every workspace wrote the standard
file set regardless of `--profile full`; `JOURNAL.md` and `evaluator-rubric.md` never appeared.

## Fix

`generateWorkspace` now destructures `tier` (defaulting to `'standard'`, matching single-repo's
default). A new `writeFullTierDocs(root, tier, opts)` writes `JOURNAL.md` and
`evaluator-rubric.md` — rendered the same way single-repo `create` does — only when
`tier === 'full'`.

**Scope decision:** single-repo's `lite` tier also drops `CONSTITUTION.md`/`FEATURES.md`, but a
workspace root's per-area constitutions and Area-tagged `FEATURES.md` route through those files
structurally (constitution routing, cross-project epics). They stay unconditional at a
workspace root regardless of tier. Only the two purely additive `full`-tier files are gated,
matching the row's own scope as written in `FEATURES.md`.
